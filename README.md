### 🧑‍💻 Sobre mim

Sou um engenheiro DevOps/SRE apaixonado por criar infraestruturas resilientes, pipelines eficientes e ambientes que *não explodem no deploy de sexta-feira*.

Tenho como filosofia o equilíbrio entre velocidade de entrega e estabilidade — aplicando práticas de SRE como SLOs, observabilidade desde o início e automação como base da confiabilidade.

### 🤓 Curiosidades Técnicas

- 🐍 **Python**: Porque às vezes shell script é pouco, mas Java é trauma.  
- ☁️ **AWS**: Te dá poder infinito... até a fatura chegar. A verdadeira elasticidade está na conta.  
- 📦 **Kubernetes**: A melhor maneira de empacotar complexidade dentro de containers e chamar isso de "orquestração".  
- 🐧 **Linux**: Onde `rm -rf /` te ensina sobre responsabilidade melhor do que qualquer bootcamp.  
- 🏗️ **Terraform**: Gosto tanto de infra como código que às vezes versiono até minha geladeira (tá no módulo `kitchen.tf`).  
- 🔍 "Funciona na minha máquina" não é desculpa — tenho CI/CD pra provar.
